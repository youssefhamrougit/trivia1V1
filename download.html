⚠ The APK isn't in the repo yet.
TriviaDuel is a web app (PWA), so there's no compiled Android package until you generate one — it takes about 2 minutes:
  1. Open pwabuilder.com → enter https://triviaduel-xi.vercel.app.
  2. Pick Android → Generate package → download the ZIP.
  3. Extract app-release.apk and drop it into the repo as apk/triviaduel.apk.
  4. Or, on Windows: double-click tools/build-apk.bat — it automates the whole Capacitor build (needs Node.js + Android Studio).
  5. This page then enables the download button automatically. Full instructions: apk/README.md.
Until then, the PWA below works right now on any phone — no file needed.

QUESTIONS

FAQ

What is an APK, and is this one safe?
An APK is the standard Android app package. This APK simply wraps the same TriviaDuel web app you'd open in a browser — there's no separate codebase. Only download it from this page, and compare the file checksum in apk/README.md if you want to be extra careful.
What's the difference between the APK and the PWA?
Functionally nothing — the PWA is installed from your browser and the APK is the same app wrapped as a file you sideload. Both run offline, both support home-screen installs. The APK is for people who prefer a real “install this file” flow.
How do updates work?
The web version updates automatically. For the APK, download the newest triviaduel.apk from this page and install over the old one — your progress (trophies, friends) is stored online, so nothing is lost.
Why isn't this on the Google Play Store?
Play Store distribution requires a $25 developer account and a review process. Sideloading the APK or installing the PWA is completely free and takes seconds — and works the exact same way.
I got a warning when installing. Is that normal?
Yes. Android shows a warning when you install apps from outside the Play Store. Tap “Install anyway” (or allow unknown apps for your browser) — this is standard for any sideloaded app.
